# 标准汉语会话360句（3）· 第1课口语练习工作台

给日语母语学生使用的第1课口语练习网页。

## 使用

- 主页模块入口：每日口语、教材内容、听力练习、课后练习。
- 每日口语小练习默认展开，点“收起”后不会遮挡其他板块。
- 进入教材、听力或课后页面时，每日口语会自动收起。

## 文件

- `index.html`：页面骨架
- `styles.css`：版式与视觉
- `app.js`：教材文本、听力任务、练习题库和页面切换
- `audio/1-1.mp3` 至 `audio/1-7.mp3`：第1课教材录音

## 录音对应关系

`app.js` 中 `audioTracks` 按以下顺序对应：

1. 1-1 标准句
2. 1-2 会话一
3. 1-3 会话一生词
4. 1-4 会话二
5. 1-5 会话二生词
6. 1-6 词语扩展
7. 1-7 语音练习

如果录音文件实际顺序不同，直接修改 `app.js` 里的标题和文本即可。

## 发布

这个文件夹是独立仓库。用 GitHub Desktop 添加并发布该文件夹后，在仓库 Settings 的 Pages 里把分支设为 `main`，就可以得到学生可访问的网址。
